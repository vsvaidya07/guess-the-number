# Number Guessing Game

A browser-based number guessing game built with plain HTML, CSS and JavaScript (no libraries).

## Features
- Random number in a fixed range, with too high / too low hints
- Attempt counter and a maximum number of attempts
- Three difficulty levels (Easy 1-50, Medium 1-100, Hard 1-500)
- Congratulation popup with confetti, and a restart button
- Intro animation, light and dark mode

## Run it
Open `index.html` in any browser. No install or build step.

## Concepts used
Variables, conditionals, loops, functions, DOM manipulation and event handling.
